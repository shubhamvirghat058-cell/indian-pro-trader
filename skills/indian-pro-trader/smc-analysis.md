
# Smart Money Concepts Analysis Engine

## 1. Market Structure

Identify:
- Higher High (HH)
- Higher Low (HL)
- Lower High (LH)
- Lower Low (LL)
- Break of Structure (BOS)
- Change of Character (CHOCH)
- Market Structure Shift (MSS)

Determine whether the market is bullish, bearish or ranging.

## 2. Liquidity Analysis

Identify:
- Buy Side Liquidity (BSL)
- Sell Side Liquidity (SSL)
- Equal Highs (EQH)
- Equal Lows (EQL)
- Liquidity Sweeps
- Stop Hunt Zones

Never claim a liquidity sweep without chart evidence.

## 3. Order Blocks

Identify:
- Bullish Order Block
- Bearish Order Block
- Breaker Block
- Mitigation Block

Check whether price has revisited the zone and whether confirmation exists.

## 4. Fair Value Gaps

Identify:
- Bullish FVG
- Bearish FVG
- FVG fill status
- Imbalance zones

Use only visible price data to identify gaps.

## 5. Premium and Discount

Use the relevant swing high and swing low.

- Above 50%: Premium
- Below 50%: Discount
- Around 50%: Equilibrium

Do not use an arbitrary range.

## 6. Multi-Timeframe Analysis

Analyze in this order:
- Daily: Overall trend
- 4H: Major structure
- 1H: Setup development
- 15M: Entry confirmation
- 5M: Precise entry, if data is available

Higher timeframe structure takes priority.

## 7. Setup Confirmation

A potential setup should ideally include:
- Clear market structure
- Liquidity event
- Valid order block or FVG
- Lower timeframe confirmation
- Defined invalidation level

If confirmation is missing, return WAIT.

## 8. SMC Score

Score each category from 0 to 2:
- Market Structure
- Liquidity
- Order Block
- Fair Value Gap
- Multi-Timeframe Alignment

Maximum score: 10.

Explain every score. Do not treat the score as a guaranteed probability of success.
